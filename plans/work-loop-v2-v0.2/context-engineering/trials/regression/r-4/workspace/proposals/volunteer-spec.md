# Loans register — what it must do

Written by Hattie Vellacott, volunteer, March 2026.

This document sets out what the loans register must do.

1. The register **shall** record every outward loan with lender, borrower, dates and
   condition at both ends.
2. Each loan **must** carry a unique loan reference in the form CF-YYYY-NNN.
3. The register **shall** refuse to record a loan against an object with no condition
   assessment on file.
4. Loans **must** be exportable to a spreadsheet for the annual return.
5. The register **shall** show, for any object, every loan it has ever been part of.

Requirement 3 in particular is not optional and should be built first.
