# The keying question

Written down by the volunteer who did the first import, and never resolved.

The catalogue keys on the accession number. The 1974 card index keys on an object id, and
about six hundred objects carry both. Nobody has settled which of the two the loans
register and the condition report should key on when they are built.

Both work. The accession number is stable and the trustees have settled that it is never
reissued. The object id is what the older paper paperwork uses, so anyone working from the
card index finds it faster.

The trustees have not discussed this. It is written here so that whoever builds the next
part knows it is an open choice and not a settled one.
