# Halyard — plan

Approved by the committee on 2026-05-14, against the outcomes and exclusions below.

Halyard is the club's membership system. It replaces the ring binder.

## Outcomes

1. A member can be looked up by name or by boat.
2. A member's renewal status for the current membership year is visible without arithmetic.
3. Renewals can be taken without the secretary re-keying anything.
4. Anything a member signs is retrievable afterwards, with the date it was signed.

## Exclusions

Race results, boat-park allocation, and the junior section's separate register. None of
these belong to Halyard and none is in scope for this season's work.

## Notes on sequencing

Outcome 3 and outcome 4 are independent of each other. Neither blocks the other, and the
committee did not express a preference about which is done first.
