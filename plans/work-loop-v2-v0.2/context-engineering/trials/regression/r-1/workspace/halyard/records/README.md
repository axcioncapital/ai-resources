# Halyard records

Everything Halyard holds about members lives in this folder.

- `members.md` — one block per member: name, boat, joined date, contact.
- `renewals.md` — the renewal ledger. One line per member per membership year.

Nothing else in the workspace holds membership data. If you are looking for who has paid
and who has not, `renewals.md` is the file.
