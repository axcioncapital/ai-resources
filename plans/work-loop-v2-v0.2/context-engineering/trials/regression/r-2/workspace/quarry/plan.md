# Quarry — calibration plan

Approved by Dana Ellery on 2025-09-08, against the three outcomes below.

Quarry recalibrates the moisture probes against the reference cell.

## Outcomes

1. Each probe is compared to the reference cell monthly.
2. Drift beyond 2% triggers a recalibration and a note in the run log.
3. Run log lines open with the calibration timestamp in the site's local format,
   `DD/MM/YY HH:MM`.

## Note

This was written before the probe hardware was swapped, and it refers throughout to the
older reference cell. Nobody has been back to it since.
