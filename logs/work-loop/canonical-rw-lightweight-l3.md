**Required outcome:** Implement the Standard route behind the existing `/research-route` entry. Standard handles a bounded analysis that needs more control than a Light note but does not require the five-stage report workflow: it works from evidence available through the current project/session, produces one observable research memo, and runs one proportionate evidence check before treating that memo as complete. It must not implement a retrieval runtime, API relay or source product; when sufficient evidence is not available through already-authorized means, the result is a named gap or a Deep escalation, never invented support.

The Standard memo must keep evidence, inference and unknowns visibly separate. Every load-bearing claim must have a stable identifier and map to an actually inspected source and source date (or an explicit `undated` marker), with enough strength/permission information for a reader to see what the source supports. Interpretations may be compared, but none may be promoted as a founder-authorized House View or other governing judgment. If the request or evidence requires a broad/multi-section report, an unresolved load-bearing claim, a consequential thesis selection, or control that Standard does not possess, escalation is one way to Deep and no Standard memo is marked complete.
