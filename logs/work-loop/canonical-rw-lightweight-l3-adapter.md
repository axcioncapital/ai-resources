**Required outcome**

Implement the smallest adapter that satisfies all of these observable behaviors:

1. A Standard assignment that does not require founder-authorized governing judgment keeps the
   accepted evidence-controlled memo behavior unchanged, including its evidence/inference separation
   and existing escalation rules.
2. When a Standard assignment genuinely requires an authorized thesis rather than a comparison of
   interpretations, the route uses L2's published consumption interface. The trigger must cover the
   existing `thesis_judgment=yes` signal when the final route remains Standard and the same need when
   it becomes apparent during Standard work; do not broaden ordinary analysis into judgment.
3. The adapter resolves one unit and base path without defining a new artifact shape. It may rely only
   on `{base}-approved.md` after L2's `check-judgment-contract.sh` returns exit `0`. Missing helpers,
   missing authority, proposed or rejected state, absent claim IDs, malformed authority and bad usage
   all fail closed. Branch on the contract's exit codes, not prose.
4. On valid authority, the Standard author receives the approved brief's content, not merely its path
   or existence, and every consequential memo assertion governed by it is traceable to the thesis it
   serves. Existing claim-level evidence permissions still bind; authority must not raise an evidence
   class or license unsupported factual language.
5. When valid approved authority is unavailable, Standard does not create, approve or simulate it and
   does not complete the judgment-bearing memo. It escalates one way to the existing Deep handoff,
   naming the authority failure sufficiently for the next route to act.
6. Proposed and rejected briefs never become authority; approved content is not authored or modified
   by the adapter; no second producer, challenge, review ledger, approval prompt, promotion path,
   House View artifact or judgment state is introduced.
7. The current blanket rejection of the reserved House View term is replaced only as far as needed to
   permit contract-valid, thesis-traced consumption. It must remain impossible for an ordinary
   Standard memo to assert or discuss governing House View authority without that binding.
